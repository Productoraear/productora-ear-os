# 💎 FASE 4: EXPERIENCIA UX/UI, FIDELIZACIÓN Y RSC (SSOT)
> **Aprobado por CEO — Octubre 2026**

Este documento define la interfaz, la estética, la lealtad y el alma operativa de EAR OS V2. 

## 1. UX/UI Y ACCESIBILIDAD 
- **Estética S-Class:** OLED Oscuro estricto (`#030305`), acentos dorados, premium y directo. Sin opción de modo claro.
- **Movilidad (PWA):** Aplicación Web Progresiva. Cero fricción, instalación directa sin comisiones de Apple/Google.
- **Autenticación (Client):** Cero contraseñas. OTP (WhatsApp/SMS) o Magic Link.
- **Internacionalización:** Multi-idioma nativo. Detección automática del navegador (clave para Destination Weddings).
- **Tono de Comunicación:** Asertivo, S-Class, directo al valor. Sin florituras. (Email solo para facturas, resto todo por WhatsApp/In-App).

## 2. NARRATIVA Y ALGORITMOS DE BÚSQUEDA
- **Algoritmo de Posicionamiento (Bodas.net Style):** Los proveedores Premium (de pago) salen los primeros. El resto rota aleatoriamente para repartir visibilidad.
- **Identidad Plataforma (Escudo Legal):** EAR OS opera estrictamente como "Tablón de Anuncios / Intermediario". Si el proveedor incumple, es un problema entre el cliente y el proveedor. EAR OS no asume responsabilidad subsidiaria del servicio prestado.
- **VIMUME (10% Social):** En el checkout el cliente es tratado como "Inversor de Impacto Social" y el sistema le emite automáticamente el Modelo 182 de la AEAT para su desgravación fiscal.
- **Social Proof VIMUME:** NO se mostrará en la web pública. La web pública mantiene un enfoque 100% comercial y elitista.
- **La Verdadera Naturaleza:** "Tinder para matching, Uber para tracking de flotas, Airbnb para espacios". Una máquina de dominancia de mercado.

## 3. FIDELIZACIÓN, B2B Y TELEMETRÍA
- **Cashback B2B (Fincas):** Las fincas obtienen un crédito/cashback, incentivando un Life Time Value (LTV) masivo. Todo con gráficas en tiempo real en el Admin.
- **Marca Blanca (Widgets):** Las fincas pueden integrar un Iframe ("Powered by EAR OS") en sus propias webs para generar referidos sin fricción.
- **Analítica para Proveedores:** Tendrán un panel telemetría (visitas, conversiones, leads perdidos). Si no tienen reservas, El Oráculo les da sugerencias proactivas (Ej: "Sube 3 fotos más").
- **Onboarding Gamificado:** Progreso guiado para obtener la insignia S-Class.
- **Acuerdos B2B (Smart Contracts):** Todo se firma automáticamente sin negociación manual.
- **Portabilidad:** Los proveedores pueden descargar sus métricas y facturas en 1 clic (ZIP).

## 4. SOPORTE, ORÁCULO Y RESEÑAS
- **Soporte Híbrido:** El Oráculo atiende el 90% por WhatsApp. Solo escala a humanos (Call Center) mediante Análisis de Sentimiento (si el cliente se enfada).
- **Alerta Médica VIMUME:** Si un centro Senior reporta problemas (Ej: Volumen alto), se oculta la cuenta y el Oráculo reporta en rojo al Call Center para auditar por negligencia.
- **Sistema NPS (WhatsApp):** 1-Clic tras el evento (1 a 5 estrellas). Solo se pide texto si la nota es alta (4-5).
- **Privacidad de Reseñas:** El cliente decide si su queja es pública o privada (solo para que EAR OS lo penalice). Los proveedores no pueden borrar críticas, deben contestar públicamente.
