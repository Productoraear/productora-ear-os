Soberanía Absoluta en Custom Claims

En la arquitectura Hermes OT, los Custom Claims de Firebase Auth representan el origen incuestionable de verdad para la autorización en tiempo real.

1

Claim de Rol

Define los privilegios lógicos del profesional: super_admin, admin_centro, terapeuta, colaborador_clinico, o solo_lectura.

2

Claim de Centro

Define la segregación geográfica obligatoria cruzada en las reglas: Centro Navalcarnero, Centro Madrid HQ, etc.

Hardening de Reglas en Firestore

El archivo firestore.rules bloquea la escalación de privilegios impidiendo la modificación de perfiles clínicos desde cliente. 

// 🏛️ Validación estricta a nivel criptográfico
match /users/{userId} {
  allow read: if isAuthenticated() && (request.auth.uid == userId || isSuperAdmin());
  allow create, update: if isAuthenticated() && (
    isSuperAdmin() || 
    (request.auth.uid == userId && 
     request.resource.data.role == resource.data.role && 
     request.resource.data.center == resource.data.center)
  );
}

Optimización de Audio Context & Hidratación

Para mantener la consistencia en Next.js (App Router), el reproductor de tonos Gamma a 40Hz aísla el ciclo de vida del contexto de audio en cliente.

✓

Aislamiento del Oscilador

Se inicializa el estado inicial en 'false'. De esta forma, el DOM inicial servido por SSR coincide al 100% con la primera carga en cliente.

✓

Destrucción de Nodos

Al detener la sesión, se liberan y destruyen todos los nodos y osciladores del procesador de audio, liberando memoria de inmediato.

Indexación Canónica (sitemap.ts)

Declarar el portal público en el sitemap dinámico de la raíz garantiza la visibilidad orgánica en Google sin exponer los dashboards privados. 

// src/app/sitemap.ts
export default async function sitemap() {
  const baseUrl = 'https://productoraear.com';
  return [
    { url: baseUrl, lastModified: new Date(), priority: 1.0 },
    { url: `${baseUrl}/vimume/hermes`, lastModified: new Date(), priority: 0.9, changeFrequency: 'weekly' }
  ];
}
