# Carpeta de Muestras de Voz de Edwin Agudelo (WhatsApp)
Coloca aquí de 2 a 5 archivos de notas de voz de WhatsApp (.mp3, .ogg, .opus, .m4a, o .wav) donde Edwin hable de presupuestos, bodas o eventos con su tono natural.
Luego ejecuta: `node scripts/clone_edwin_voice.cjs` para crear el clon de voz en la nube sin usar GPU local.
