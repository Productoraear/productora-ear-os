# 🏛️ EAR OS V2 GOLD: LA CONSTITUCIÓN MAESTRA (S-CLASS)

Este documento es el **Oráculo de Verdad** para el desarrollo de EAR OS V2 GOLD. Consolida todas las directivas de arquitectura, diseño, inteligencia y negocio extraídas de los grimorios históricos y las sesiones de ingeniería de Silicon Valley.

---

## 🛰️ 1. VISIÓN ESTRATÉGICA (EAR OS SOVEREIGN)
**Objetivo**: Consolidar EAR OS como el estándar mundial de gestión y producción bajo estándares de renderizado WebGPU avanzados y orquestación RAG proactiva.

**Pilares**:
- **EVENTOS (productoraear.com)**: Vertical corporativa B2B de alto impacto.
- **VIMUME (viajemusicalporlamemoria.com)**: Vertical de impacto social y restauración de memoria.
- **ARTISTAS (artistaseuropa.com)**: Vertical de marketplace y aceleradora de talento (ASTRA).

---

## 🛠️ 2. STACK TECNOLÓGICO S-CLASS (REGLAS DE ORO)
- **Core**: React / Next.js 16 (App Router), TypeScript Strict.
- **Styling**: Tailwind CSS + Vanilla CSS (Glassmorphism, Minimalismo Corporativo).
- **Animaciones**: Framer Motion + GSAP (ScrollTrigger) para narrativa inmersiva.
- **Visualización**: Three.js + React Three Fiber (R3F) + WebGPU (GLSL/WGSL Shaders).
- **Backend/IA**: Firebase/Supabase (PostgreSQL + Pgvector) + Python (Inferencia RAG).
- **Soberanía**: IPFS/Arweave para activos críticos; cifrado AES-256.

---

## 🎨 3. LEY DE LA HOJA DESÉRTICA (EFICIENCIA EXTREMA)
- **Fotosíntesis de Tokens**: Máxima funcionalidad con mínimos recursos.
- **Batching Masivo**: No editar línea por línea; escribir componentes completos y funcionales en una pasada.
- **Eradicación del "Código Escaparate"**: Todo botón, link y CTA debe ser funcional y estar vinculado a la telemetría (Tripwire).

---

## 🧠 4. ARQUITECTURA DE INTELIGENCIA (RAG BRAIN)
- **Modelos**: Gemini 1.5 Pro (Inferencia principal) / Claude 3.5 Sonnet.
- **Motor RAG**: Búsqueda híbrida (Semántica + Keywords) en Qdrant/Supabase.
- **Latencia Cero**: Pre-renderizado en GPU y cacheo predictivo de intención.
- **Scanner de Intención**: El sistema debe anticipar la necesidad del usuario (ROI, Viabilidad, Talento).
