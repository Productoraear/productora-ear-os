# 📖 INSTRUCCIONES DE EJECUCIÓN — OMNI-EXTRACTOR

Este script es tu **Bala de Plata** para unificar el Imperio disperso. Sigue estos pasos con rigor militar.

## 🛠️ Requisitos Previos

1. **Node.js**: Asegúrate de tener Node.js instalado (`node -v`).
2. **Discos Montados**: Asegúrate de que las unidades **H:**, **F:** y **D:** estén conectadas y accesibles en tu sistema Windows.
3. **Sin Dependencias Externas**: El script utiliza módulos nativos de Node.js (`fs`, `path`) para garantizar compatibilidad total sin necesidad de `npm install`.

## 🚀 Ignición del Script

Abre tu terminal (PowerShell o CMD) en la raíz del proyecto (`c:\EAR_OS_V2`) y ejecuta:

```powershell
node omni_extractor.js
```

## 📊 ¿Qué sucederá?

1. **Escaneo Atómico**: El script recorrerá cada disco buscando archivos `.tsx`, `.ts`, `.md`, `.json`, `.py`.
2. **Vampirización**: Si encuentra duplicados, seleccionará el archivo con mayor densidad de código como la base y marcará los demás como fragmentos complementarios.
3. **Mapeo de Gigantes**: Clasificará cada módulo según si aporta lógica de Uber, Airbnb, Tinder o Bodas.net.
4. **Generación del CODEX**: Se creará el archivo `EAR_OS_OMEGA_CODEX.md` en tu carpeta actual.

## 🏛️ El Entregable: OMEGA_CODEX.md

Este archivo contendrá:
- El árbol genealógico completo de tu código.
- Los 10 niveles de cascada organizados.
- La ruta exacta de cada pieza y su "Ventaja Injusta".

**Ejecuta y recupera tu Soberanía.**
