## III. Componentes S-Class: Glassmorphism + Motion

Cada componente debe incluir nativamente:

### Diseño Visual
```typescript
// Glassmorphism base
className="bg-white/10 backdrop-blur-md border border-white/20 rounded-2xl"

// Efecto de profundidad
className="shadow-[0_8px_32px_0_rgba(31,38,135,0.37)]"
```

### Animaciones
- **Entrada**: `initial={{ opacity: 0, y: 20 }}` → `animate={{ opacity: 1, y: 0 }}`
- **Hover**: Transforms dinámicos con `whileHover`, `whileTap`
- **Transiciones**: `transition={{ duration: 0.3, ease: "easeInOut" }}`
