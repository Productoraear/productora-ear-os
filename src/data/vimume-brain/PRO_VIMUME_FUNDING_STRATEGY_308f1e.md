### 5.2 Campaña Propuesta: "50 Sesiones para 200 Abuelos"

> **Referencia real:** El proyecto "Musicoterapia para conectar recuerdos" en Migranodearena (mayo 2025) buscó financiar exactamente esto: 50 sesiones para 200+ personas mayores con Alzheimer.

#### Estructura de la Campaña

```
Meta mínima:  €5.000 (cubre 15 sesiones piloto)
Meta óptima:  €15.000 (cubre 50 sesiones + materiales)
Meta stretch: €25.000 (50 sesiones + VIMUME Tracker MVP)

Duración: 40 días
Plataforma primaria: Goteo (ventajas fiscales para donantes)
Plataforma secundaria: Migranodearena (causa solidaria)
```

#### Recompensas Escalonadas

| Aporte | Recompensa |
|--------|-----------|
| €10 | Agradecimiento digital + nombre en web |
| €25 | Video exclusivo de sesión VIMUME |
| €50 | Certificado de "Mecenas Musical" + acceso a reportes de impacto |
| €100 | Invitación a sesión VIMUME en directo |
| €250 | Mini-concierto privado mariachi (30 min) |
| €500 | Patrocinio de 1 sesión completa (nombre visible) |
| €1.000+ | "Padrino/Madrina VIMUME" — Patrocinio de 3 sesiones + informe personalizado |

#### Ventajas Fiscales (Goteo)

```
Personas físicas: Deducción del 80% sobre los primeros €250 donados
                  + 40% sobre el resto (45% si recurrente)
Empresas:         Deducción del 40% (50% si recurrente)
                  (Ley 49/2002 modificada 2023)
```

#### Calendario de Campaña

```
Semana -4 a -1: Pre-lanzamiento (100 contactos personales, email)
Semana 1:       Lanzamiento fuerte (30% del objetivo en 72h)
Semana 2-3:     Contenido de impacto (videos, testimonios)
Semana 4:       Push intermedio (actualización de progreso)
Semana 5:       Sprint final (urgencia + stretch goals)
Semana 6:       Cierre + agradecimiento público
```

## 8. MODELO TELETÓN ADAPTADO

### 8.1 Concepto: "VIMUME Live: Música que Despierta Memorias"

> Adaptar el modelo Teletón latinoamericano (Colombia, Chile, México) a un formato digital/streaming más viable para un proyecto emergente en España.

#### Formato Propuesto

```
NO es una Teletón tradicional (27h TV nacional)
SÍ es un "Streaming Solidario Musical" de 4-6 horas

Plataforma: YouTube Live + Instagram Live + TikTok Live
Contenido:
├── Conciertos en vivo (mariachi + artistas invitados)
├── Testimonios de familias y residentes
├── Intervenciones de neurocientíficos/médicos
├── Sesión VIMUME en directo desde un centro
├── Contador de donaciones en tiempo real
└── Retos solidarios (#RetoVIMUME)
```

#### Modelo de Ingresos del Evento

| Fuente | Estimación |
|--------|-----------|
| Donaciones voluntarias streaming | €2.000-€8.000 |
| Patrocinios empresas (mención en directo) | €3.000-€10.000 |
| Venta de merchandise solidario | €500-€2.000 |
| "Apadrina una canción" (€5/canción dedicada) | €1.000-€3.000 |
| **Total estimado** | **€6.500-€23.000** |

#### Referencia Teletón (Latinoamérica)

```
Chile 2025:  ~$50M CLP (~€50K)
Perú 2025:   ~S/9.2M (~€2.3K... ok, mucho menos)
El Salvador:  ~$2.4M USD
Colombia:     75% ciudadanía + 25% empresas
```

**Aprendizaje clave:** El 75% del éxito viene de la ciudadanía, no de empresas. La emoción y la historia personal son el motor principal.
