## 2. CAPAS DE LA ARQUITECTURA

### 1. Root Intelligence Layer
Define la identidad canónica del repositorio a través de firmas semánticas, manifiestos de versión y hashes del SSOT (`01_SSOT_Y_KERNELS/CLINE_OMEGA_KERNEL.md`).

### 2. Full-PC Discovery Layer
Recorre las unidades visibles en modo seguro (metadata-first, content-second por score) respetando rutas del sistema y protegiendo secretos (`.env`, llaves, tokens).

### 3. Relationship Graph Layer
Construye el Grafo de Conocimiento Estructural (`EAR_OS_KNOWLEDGE_GRAPH.md`) registrando nodos y aristas ponderadas de parentesco.

### 4. Mental Model Layer
Genera la interfaz de lectura humana (`EAR_OS_EXECUTIVE_MINDMAP.md`) estructurada en 5 anillos funcionales.

### 5. Absorption Control Layer
Gestión del ciclo de vida: `OBSERVE` -> `TAG` -> `LINK` -> `STAGE` -> `QUARANTINE` -> `ABSORB`. Absorción 100% aditiva con rollback atómico.

### 6. Runtime & Observability Layer
