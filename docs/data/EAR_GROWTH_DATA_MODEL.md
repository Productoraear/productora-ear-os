# 🌱 EAR OS — GROWTH DATA MODEL

> **Moat Defensable de Datos:** Estructuración del conocimiento extraído de la operación diaria para realimentar el SEO, el RAG y el CRM. El mayor activo de Productora EAR.

## 1. Datos Capturados para el Moat
- **Objeciones Comunes:** Razones de "Win/Loss" (ej. "Precio alto", "Quería otro repertorio").
- **Preguntas Reales del Usuario:** (Query Logs del RAG).
- **Rutas de Conversión de Alta Velocidad:** (Ej. Usuarios de Madrid reservan en 5 mins vs. 48h en Barcelona).
- **Zonas Calientes (Heatmaps):** Geografías con alta demanda insatisfecha (muchas queries, pocas ventas).

## 2. Ciclo de Retroalimentación (The Flywheel)
- **Las Preguntas Reales** alimentan las FAQs de las nuevas Landings Programáticas (Mejora el SEO).
- **Las Objeciones de Pérdida** alimentan el Prompt del RAG para manejarlas proactivamente en futuras charlas (Mejora la Conversión).
- **Las Zonas Calientes** disparan la creación de nuevas familias de URLs y campañas Ads enfocadas en esas ciudades (Mejora la Adquisición).
