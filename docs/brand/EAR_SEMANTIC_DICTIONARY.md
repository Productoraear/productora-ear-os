# 📖 EAR OS — SEMANTIC DICTIONARY (PREMIUM POSITIONING)

> **Diccionario Semántico:** Reglas inmutables de lenguaje para elevar la percepción de la marca Edwin Agudelo, aplicables a Front-end, Prompts del LLM, Campañas SEO y Operaciones CRM.

## 1. Reglas Core de Comunicación
1. **La marca no compite por precio:** Compite por calidad del mensaje, cuidado del lenguaje, presencia escénica y personalización.
2. **Cero Agresividad Comercial:** Evitar el "Compra ya", "Oferta por tiempo limitado" o "Aprovecha hoy". Usar lenguaje consultivo y elegante.
3. **Validación del Elogio:** Palabras como "increíble", "inolvidable" o "único" solo se usan si están ancladas a una review real o contexto demostrado, no como promesas vacías.

## 2. Léxico Prohibido vs. Lenguaje Aprobado

| 🚫 Prohibido (Degrada la Marca) | ✅ Aprobado (Eleva la Marca) | Contexto de Uso |
|:---|:---|:---|
| Barato, Económico, Low Cost | Esencial, Formato Compacto, Inversión Accesible | Formatos solista o trío. |
| Oferta, Chollo, Descuento | Propuesta a medida, Ventaja por cierre temprano | Negociaciones CRM. |
| Contratar mariachi | Reservar experiencia musical, Asegurar disponibilidad | CTA principal en landings. |
| Tocar canciones | Interpretar un repertorio, Brindar una presentación | Descripción del servicio. |
| Mariachi para fiestas | Experiencia para celebraciones, Presencia escénica | SEO / Landings B2C. |
| Presupuesto sin compromiso | Solicitar propuesta, Consultar disponibilidad | Formularios de contacto. |

## 3. Redefinición de Ocasiones
- **Bodas:** Ceremonia, celebración nupcial, gala, emoción, cuidado.
- **Cumpleaños:** Homenaje, sorpresa, celebración íntima, festejo familiar.
- **Serenatas:** Dedicatoria, detalle protocolario, presencia emocional.
- **Pedidas:** Momento clave, preparación cuidadosa, discreción, sensibilidad.

## 4. Redefinición de Formatos
- **Solista:** Formato compacto, versión esencial (ideal para espacios íntimos).
- **Trío:** Presencia equilibrada, serenata clásica.
- **Cuarteto:** Formato de gala, presencia escénica completa.
- **Gran Show / 8+ Músicos:** Experiencia premium, impacto masivo, formato de gran escala.
