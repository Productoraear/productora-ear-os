## 1. DIAGNÓSTICO SEO / GEO / B2G

### SEO
- Sitemap: correcto.
- Indexación: correcta, pero existe riesgo de thin content en nodos territoriales.
- Interlinking: insuficiente para distribuir autoridad entre servicios, territorios y páginas de confianza.
- Canonicals / metadata: funcionales, pero necesitan consistencia reforzada por plantilla.

### GEO / AEO
- Estado: bajo a medio.
- Problema: falta una capa de entidad clara, factual y citable por IA.
- Necesidad: schema dinámico, bloques de definición, FAQs verificables, comparativas y lenguaje orientado a extracción.

### B2G
- Estado: emergente.
- Riesgo: no hay suficiente arquitectura específica para ayuntamientos, cultura pública, eventos institucionales o licitaciones.
- Necesidad: páginas de autoridad, trust signals, cobertura, metodología, cumplimiento y proceso de contratación.

## 2. TERRITORIAL DOMINANCE ENGINE

### Estructura de URL
- `/servicios/[servicio]/[provincia]`
- `/servicios/[servicio]/[ciudad]` solo cuando haya valor real y cobertura real.
- `/metodologia-ear-gold`
- `/soberania-tecnica`
- `/vimume-social-impact`
- `/eventos-ayuntamientos/[provincia]`
- `/contratacion-cultural/[provincia]`

### Reglas
- Prohibido el copy clonado por ciudad.
- Cada landing debe incorporar contexto local real.
- Cada página debe tener intención clara: información, comparación, contratación o solicitud.
- Cada bloque debe ser útil tanto para humanos como para IA.

---

## 3. ANTI-THIN CONTENT POLICY

Cada página territorial debe incluir:
- H1 específico y natural.
- Respuesta clara a la intención de búsqueda.
- 1 bloque editorial único.
- 1 bloque de FAQs locales.
- 1 bloque de confianza o prueba.
- 1 bloque de servicio o proceso.
- 1 CTA contextual.
- 1 capa de schema coherente.

Si una página no puede sostener eso, no merece existir.
