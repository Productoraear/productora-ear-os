# Funnel, CRM y consentimiento

## Principio
Captación mediante opt-in explícito; no scraping ni extracción de perfiles sociales.

## Flujo candidato
Contenido -> landing -> consentimiento -> solicitud -> entrega -> testimonio autorizado -> recomendación.

## Datos mínimos
- Nombre solicitado
- Canal de respuesta elegido
- Consentimiento
- Fuente
- Fecha de registro

## Pendiente
Política de privacidad, retención y mecanismo de baja.
